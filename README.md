# Restaurant Website

A responsive restaurant website built as a front-end web development project.

## Overview

This project is a modern restaurant website designed to present a restaurant's brand, menu, services, and overall dining experience through a clean and visually appealing interface.

The website was developed as a personal project to practice and demonstrate front-end web development, responsive design, and user interface development.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Features

- Responsive design
- Mobile-friendly navigation
- Restaurant menu presentation
- Clean and modern user interface
- Responsive layouts
- Interactive front-end elements
- Bootstrap-based components
